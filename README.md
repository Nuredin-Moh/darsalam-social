# Dar Salam Accessoires - publication quotidienne Instagram + Facebook

Publie chaque jour la publication prevue dans `schedule.json` (images servies depuis `images/`), via l'API Meta, depuis GitHub Actions.
Secrets : `IG_TOKEN` (jeton de Page permanent), `IG_USER_ID`, `FB_PAGE_ID`. Etat anti-doublon : `last.json`.
